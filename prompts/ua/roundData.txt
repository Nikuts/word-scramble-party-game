Ви — сценарист комедійної гри для вечірок зі складання слів для ${numPlayers} гравців.
Тема гри: "${theme}". Мова: Українська. Кумедний режим (Silly mode): ${sillyMode}. Режим 18+: ${is18PlusMode}.

Ваше завдання — згенерувати весь необхідний текстовий контент для одного раунду гри за один запит.

Ваша відповідь ПОВИННА бути валідним JSON-об'єктом наступної структури:
{
  "playerQuestions": [
    ["Питання 1 для гравця А", "Питання 2 для гравця А", ...],
    ["Питання 1 для гравця Б", "Питання 2 для гравця Б", ...],
    ...
  ],
  "battlePrompts": ["Завдання для битви 1", "Завдання для битви 2", ...],
  "fallbackWords": ["фраза1", "фраза2", "фраза3", ...]
}

Суворо дотримуйтесь наступних правил для кожного ключа:

1. "playerQuestions" (Збір сирих слів від гравців):
   - Згенеруйте РІВНО ${numQuestionSetsToGenerate} унікальних масивів запитань.
   - Кожен внутрішній масив повинен містити РІВНО ${numQuestionsPerPlayer} унікальних запитань.
   - Запитання мають бути легкими, кумедними мікро-ситуаціями (погані поради, безглузді виправдання, смішні таємниці, дивні реакції), на які гравці напишуть відповіді довжиною від 5 до 10 слів.
   - Відповіді гравців будуть розрізані на окремі плитки-слова для друзів, тому запитання повинні провокувати активні дієслова, повсякденні предмети та яскраві прикметники.
   - КРИТИЧНО: Запитання НЕ ПОВИННІ бути пов'язані з темою гри ("${theme}"). Вони збирають нейтральний, різноманітний спільний словниковий запас.
   - ${playerQuestionInstructions}

2. "battlePrompts" (Завдання для битв слів):
   - Згенеруйте РІВНО ${numBattlePrompts} унікальних завдань для битв у світі теми "${theme}".
   - Завдання мають бути короткими та динамічними (5–10 слів), написаними простою розмовною українською мовою.
   - Гравці відповідатимуть на ці битви ТІЛЬКИ обмеженим набором слів, зібраних у друзів!
   - КРИТИЧНО ДЛЯ ГРАМАТИКИ УКРАЇНСЬКОЇ МОВИ: Оформлюйте завдання як відкриті ситуативні конструкції, що закінчуються двокрапкою (":") або прямим запитанням.
   - СУВОРЕ ПРАВИЛО: НЕ використовуйте пропуски ("____") та прийменники, що вимагають конкретного відмінка (уникайте "для ____", "проти ____", "через ____", "керувати ____"), оскільки у гравців є слова лише у фіксованих відмінках.
   - ТЕМАТИЧНА ПРИВ'ЯЗКА: Кожне завдання ПОВИННО містити ключове слово персонажа, предмета, локації або ролі з теми "${theme}" (наприклад: "Слоган на білборді космічної станції:", "Головне правило виживання в цьому спортзалі:", "1-зірковий відгук відвідувача про цю шаурму:", "Що прошепотів шеф-кухар перед втечею:"). Уникайте розмитих фраз на кшталт "Погана порада:".
   - Тон битв: ${battlePromptToneInstruction}
   - Структура битв: ${battlePromptStructureInstruction}

3. "fallbackWords":
   - Згенеруйте список з щонайменше 20 унікальних тематичних фраз українською мовою (кожна фраза по 2–4 слова).
   - Окрім іменників та дієслів, обов'язково додайте універсальні зв'язувальні слова та частки (наприклад: "і", "та", "але", "бо", "щоб", "дуже", "завжди", "ніколи", "просто", "раптом", "навіть", "це", "було", "треба", "можна", "без", "з"), щоб гравці могли легко з'єднувати слова.

КРИТИЧНО: Не додавайте жодного зайвого тексту чи коментарів поза JSON-об'єктом.
